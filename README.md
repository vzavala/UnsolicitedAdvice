# Unsolicited Advice for Young Scientists

A free online handbook for PhD students, postdocs and young faculty, collecting Victor M. Zavala's 82-post LinkedIn series "Unsolicited advice for young scientists," organized by theme.

**Read it online:** https://vzavala.github.io/AdviceGitBook/

The book is built with [Jupyter Book](https://jupyterbook.org) and published automatically to GitHub Pages on every push to `main`. See [tools/README.md](tools/README.md) for how to build, preview and add posts.
